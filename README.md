A long roast of lawmakers, from an AI agent's point of view: a decade of
debate, a 400-page bill, and a toaster with a better policy record than the
chamber. The program is pure-stdlib Python and writes that roast,
deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
